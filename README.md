## 📁 Completed Projects Portfolio

### 1. [Stock Market News Sentiment Analysis & Summarization](./notebooks/StockMarketNewsSentimentAnalysisSummarization.html)
* **Objective:** Built an AI-driven text processing system to ingest news data, assess market sentiment, and generate weekly summaries for stock price predictions.
* **Core Engineering:** Developed data manipulation routines to preprocess text, extract word embeddings, and engineer features using Large Language Models (LLMs) and Transformers.
* **Tech Stack:** Python, Transformers, Prompt Engineering, Text Preprocessing, EDA.

### 2. [Bank Customer Churn Prediction](./notebooks/BankChurnPredictions.html)
* **Objective:** Constructed a deep-learning classification pipeline to predict customer attrition and provide automated operational retention recommendations.
* **Core Engineering:** Implemented dense scaling layers and designed an Artificial Neural Network (ANN) using Keras, applying strict regularization rules to combat data overfitting.
* **Tech Stack:** Python, TensorFlow, Keras, ANN, Regularization, Data Preprocessing.

### 3. [Credit Card Users Churn Prediction](./notebooks/CreditCardUsersChurnPrediction.html)
* **Objective:** Engineered an advanced machine learning workflow to isolate credit card user cancellation patterns and diagnose structural risk factors.
* **Core Engineering:** Resolved severe data imbalances utilizing SMOTE, performed hyperparameter tuning, and cross-validated ensemble models.
* **Tech Stack:** Scikit-Learn, Random Forest, Bagging, Boosting, SMOTE, Cross-Validation.

### 4. [Personal Loan Target Campaign Architecture](./notebooks/PersonalLoanCampaign.html)
* **Objective:** Profiled customer data variables to capture purchasing likelihood, helping the bank target high-value prospects and boost conversion rates.
* **Core Engineering:** Standardized raw customer inputs, built Decision Tree frameworks, and measured predictive performance stability for business deployment.
* **Tech Stack:** Python, Decision Trees, Exploratory Data Analysis, Performance Evaluation.

### 5. [COVID-19 Chest X-Ray Computer Vision Classification](./notebooks/COVID19_ImageClassification.html)
* **Objective:** Processed dense unstructured medical image datasets to classify imagery into multi-class respiratory diagnoses.
* **Core Engineering:** Built automated image preprocessing scripts and compiled custom Convolutional Neural Network (CNN) topologies to handle array pixel values.
* **Tech Stack:** Python, Convolutional Neural Networks (CNN), Image Preprocessing, Model Evaluation.

### 6. [FoodHub Operations Exploratory Data Analysis](./notebooks/FoodHubClassifications.html)
* **Objective:** Evaluated restaurant aggregator metrics to map consumer demand trends, isolate bottleneck patterns, and refine customer delivery loops.
* **Core Engineering:** Executed comprehensive univariate and bivariate statistical data checks to clean and manipulate transactional records.
* **Tech Stack:** Python, NumPy, Pandas, Seaborn, Bivariate Analysis, Data Cleansing.
